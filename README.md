# Test GitHub Agent

A test project for trying out Claude Code GitHub Actions integration.

## Setup

This project includes a simple calculator module to test Claude Code's ability to:
- Fix bugs (division by zero)
- Add features (power, square root functions)
- Review code

## Usage

```bash
npm start    # Run demo
npm test     # Run tests
```

## Claude Code Integration

This repo has Claude Code GitHub Actions set up. You can:
- Comment `@claude` on issues or PRs to ask questions
- Assign issues to Claude to have it implement fixes
- Claude will auto-review PRs when opened
